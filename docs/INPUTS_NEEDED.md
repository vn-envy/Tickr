## Helpful for stronger intelligence

- Owner-provided customer review/export excerpts, with source and date; redact unnecessary personal details.

- A clear offer constraint: margin floor, excluded days, limited stock or services the business cannot promise.

## Secure configuration and access handling

Keep secrets server-side in environment settings or an ignored local configuration file following README.
Repository examples list variable names only. Do not add credentials, raw authorization headers or tokens to fixtures, screenshots, logs or exports.
Check existing binding names/presence and actual supported requests before requesting duplicate credentials.
If the Meta API requires additional verified asset-download hosts, record those exact destinations after observing the supported response flow.
Website reading has a separate restricted public-site path; it is not permission for arbitrary outbound APIs.

Social account permissions are optional later inputs. Request them only when implementing an explicitly chosen publishing/insights integration.
Drafting a CTWA script or Status creative requires no social account connection; activating a placement requires separate eligibility and owner authorization.
Nothing in this setup authorizes messaging customers, publishing posts or spending ad budget.
